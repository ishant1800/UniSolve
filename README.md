# UniSolve
UniSolve – AI-Powered Campus Helpdesk System

## Backend Setup

1. Navigate to the backend folder:
   ```bash
   cd server
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` and fill in `MONGO_URI`, `JWT_SECRET`, and `OPENAI_API_KEY`.
4. Start the server:
   ```bash
   npm run dev
   ```
