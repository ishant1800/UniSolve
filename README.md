# 🧠 UniSolve – AI-Powered Campus Helpdesk System

UniSolve is a full-stack MERN application designed to streamline campus issue reporting and resolution using AI-powered ticket classification.

---

## 🚀 Features

- 🔐 User Authentication (JWT-based)
- 🎫 Ticket Management System (CRUD)
- 🤖 AI-powered ticket creation (auto title, description, priority, department)
- 💬 Conversational AI for smart ticket generation
- ⏱ SLA-based ticket prioritization
- 🔔 Real-time updates (Socket.io)
- 📊 Dashboard with analytics

---

## 🏗 Tech Stack

**Frontend:**
- React (Vite)
- Tailwind CSS
- Axios

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)

**AI Integration:**
- OpenAI API (GPT-4o-mini)

**Deployment:**
- Frontend: Vercel
- Backend: Render
